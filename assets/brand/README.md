# Brand assets for generated documents

Copied unchanged from the GGO Med Design System kit, used by
`lib/contracts/pdf.ts` to lay out signed agreements.

- `ggo-med-logo-purple.png`: the approved purple-on-white logo
  (`assets/logo-purple-on-white.png` in the kit), with the empty margin
  around the mark trimmed and scaled to 500 px high. The mark itself is untouched.
- `PlusJakartaSans-*.ttf`: Plus Jakarta Sans, the kit's typeface.
  Copyright 2020 The Plus Jakarta Sans Project Authors
  (https://github.com/tokotype/PlusJakartaSans), licensed under the SIL Open
  Font License, Version 1.1 (https://openfontlicense.org).

Replace these only with files from the kit.
